REPORT GENERATOR EXAMPLES
=========================

These examples show how to call generate_report() directly
or trigger it through the interactive CLI.

--------------------------------------------------------------
Example 1 — Quarterly sales report (dict data)
--------------------------------------------------------------
data = {
    "January":  50000,
    "February": 65000,
    "March":    80000
}

assistant.generate_report(
    report_type="quarterly",
    data=data,
    period="Q1 2026"
)

Expected output structure:
    ============================================
    Q1 2026 QUARTERLY BUSINESS REPORT
    ============================================
    Date   : May 22, 2026
    Period : Q1 2026

    EXECUTIVE SUMMARY
    Q1 2026 delivered strong growth with total revenue of PKR 195,000...

    KEY METRICS
    - Total        : 195,000
    - Average      : 65,000
    - Peak Period  : March (80,000)
    - Lowest Period: January (50,000)
    - Growth Rate  : 60.0%
    - Trend        : Increasing

    DATA ANALYSIS
    [Detailed paragraph]

    RECOMMENDATIONS
    1. ...
    2. ...
    ============================================

--------------------------------------------------------------
Example 2 — Six-month revenue report (list data)
--------------------------------------------------------------
data = [50000, 58000, 65000, 61000, 72000, 80000]

assistant.generate_report(
    report_type="revenue",
    data=data,
    period="H1 2026"
)

--------------------------------------------------------------
Example 3 — Marketing performance report
--------------------------------------------------------------
data = {
    "January":  420,
    "February": 510,
    "March":    595,
    "April":    480
}

assistant.generate_report(
    report_type="marketing",
    data=data,
    period="Q1 2026"
)

Note: Values here represent leads generated per month.

--------------------------------------------------------------
Example 4 — Performance report with KPI scores
--------------------------------------------------------------
data = {
    "Ali":    87,
    "Sara":   92,
    "Usman":  78,
    "Fatima": 95,
    "Bilal":  83
}

assistant.generate_report(
    report_type="performance",
    data=data,
    period="May 2026"
)

--------------------------------------------------------------
CLI usage
--------------------------------------------------------------
Select option: 2
  Report type : quarterly
  Period      : Q1 2026
  Data        : {"Jan": 50000, "Feb": 65000, "Mar": 80000}

Tip: Use double quotes inside the JSON when typing in the CLI.
